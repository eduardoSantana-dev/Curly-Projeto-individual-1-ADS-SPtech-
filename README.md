# 📖 Sobre o projeto

A Curly é uma plataforma desenvolvida com o objetivo de conectar pessoas com cabelos ondulados, cacheados e crespos através do compartilhamento de experiências, inspirações e dicas sobre cuidados capilares.

Além das funcionalidades sociais, a plataforma conta com uma galeria de inspirações, sistema de seguidores, área administrativa para gerenciamento do sistema e a CacheIA, uma assistente virtual voltada para dúvidas relacionadas aos cabelos cacheados.

---

# ✨ Funcionalidades

### 👤 Usuários

* Cadastro e login;
* Edição de perfil;
* Upload de foto de perfil;
* Alteração de tema.

### 📝 Publicações

* Criação de posts;
* Curtidas;
* Comentários;
* Galeria de inspirações.

### 👥 Social

* Sistema de seguidores;
* Perfis de usuários.

### 🤖 CacheIA

* Assistente virtual integrada para dúvidas e recomendações.

### 🛠 Área Administrativa

* Gerenciamento de usuários;
* Gerenciamento de posts;
* Dashboard com métricas da plataforma.

# ⚙️ Como usar

### 1. Clone este repositório em sua máquina

```bash
git clone https://github.com/eduardoSantana-dev/Curly-Projeto-individual-1-ADS-SPtech-
```

---

### 2. Crie as tabelas necessárias no Banco de Dados

Siga as instruções presentes no arquivo:

```text
/src/database/script-curly.sql
```

---

### 3. Configure o ambiente da aplicação

Acesse o arquivo:

```text
app.js
```

e parametrize o ambiente.

* Caso esteja utilizando o ambiente de produção, habilite:

```javascript
var ambiente_processo = 'producao';
```

* Caso esteja utilizando o ambiente de desenvolvimento, habilite:

```javascript
var ambiente_processo = 'desenvolvimento';
```

---

### 4. Configure as credenciais do banco

Adicione as informações de conexão no arquivo:

```text
.env
```

ou

```text
.env.dev
```

seguindo as instruções presentes neles.

---

### 5. Instale as dependências

No terminal, execute:

```bash
npm i
```

Este comando instalará todas as bibliotecas necessárias para a execução do projeto, listadas no arquivo `package.json`.

Ao final da instalação, será criada automaticamente a pasta:

```text
node_modules
```

que contém todas as dependências utilizadas pelo sistema.

---

### 6. Inicie a aplicação

Execute:

```bash
npm start
```

A aplicação será iniciada conforme a configuração realizada anteriormente.

---

### 7. Acesse o projeto

Após a inicialização, abra em seu navegador o endereço informado no terminal.

---

### 8. Encerrar a execução

Para interromper a aplicação, pressione:

```text
CTRL + C
```

no terminal em que ela estiver sendo executada.

# 🎓 Projeto Acadêmico

A Curly foi desenvolvida como um projeto acadêmico da disciplina de Pesquisa e Inovação, do primeiro semestre do curso de Análise e Desenvolvimento de Sistemas da SPTech School. O projeto teve como objetivo reunir e aplicar, em uma solução individual, os conhecimentos adquiridos ao longo do semestre. Além disso, buscou-se desenvolver uma solução alinhada aos meus interesses e experiências pessoais, abordando um tema com o qual me identifico e que considero relevante, unindo socioEmocional e aprendizado técnico em um único projeto.
